# Contributing

This repository follows CyberZonic enterprise engineering standards.

## Contribution Principles

- Keep changes scoped and reviewable
- Prefer automation over manual changes
- Include verification evidence for meaningful changes
- Do not commit secrets or local environment files
- Update documentation when behaviour changes
- Preserve security, auditability, and operational quality
- Avoid shortcuts that create future product, security, or architecture debt

## Branching

The default branch is main.

Expected future development model:

- Feature branches for implementation changes
- Pull requests for review
- Clear commits with meaningful messages
- No force pushes to protected/shared branches
- Release or deployment changes backed by evidence
