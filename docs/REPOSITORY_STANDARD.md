# CyberZonic Repository Standard

## Required Files

Each repository should maintain:

- README.md
- SECURITY.md
- CONTRIBUTING.md
- .github/CODEOWNERS
- .github/PULL_REQUEST_TEMPLATE.md
- .github/ISSUE_TEMPLATE/config.yml
- docs/GOVERNANCE.md
- docs/REPOSITORY_STANDARD.md
- docs/SECURITY_CLASSIFICATION.md
- docs/OPERATIONAL_MODEL.md
- docs/CHANGE_CONTROL.md

## Visibility Standard

- Product source code: private
- Sensitive architecture: private
- Infrastructure: private
- Security baselines: private unless explicitly approved for public release
- Brand/commercial assets: private
- Safe foundation/standards: public where useful
- Organisation profile: public

## Evidence Standard

Every serious implementation phase should produce command output, test output, verification logs, security scan results, reports, screenshots where appropriate, and a pass/fail matrix.
