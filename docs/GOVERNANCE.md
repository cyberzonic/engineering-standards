# CyberZonic Repository Governance

## Purpose

This repository is governed as part of the CyberZonic engineering estate.

## Governance Controls

- Repository ownership is controlled by the CyberZonic organisation.
- Product and operational repositories are private by default.
- Public repositories must contain only safe, non-sensitive material.
- Repository changes should be traceable through commits and pull requests.
- Secrets, credentials, and production configuration must not be committed.
- Branch protection should be enabled once baseline commits and CI workflows exist.
- External collaboration must follow least privilege.

## Ownership Model

Initial owner/admin identity:

- cyberzonic-engineering

Planned identities:

- cybsecaibot for automation/service operations
- platform-engineering for delivery
- security-reviewers for security governance
- product-leadership for roadmap and product governance
- external-collaborators for controlled third-party access
