# Operational Model

## Operating Model

This repository follows the CyberZonic enterprise operating model:

1. Verify current state.
2. Apply controlled change.
3. Produce evidence.
4. Review security/operational impact.
5. Document outcome.
6. Preserve rollback path.

## Automation Standard

Automation should be idempotent where practical, evidence-producing, safe by default, re-runnable, least privilege, clear about manual checkpoints, and explicit about rollback guidance.

## Closure Criteria

A phase should not close on summary text alone. It should include commands run, outputs/evidence, artifact/report paths, pass/fail matrix, and unresolved advisories.
