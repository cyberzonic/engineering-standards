# Security Classification

## Classification Levels

| Level | Meaning | Example |
|---|---|---|
| Public | Safe to publish externally | General engineering standards |
| Internal | CyberZonic internal use | Architecture notes, governance docs |
| Confidential | Sensitive commercial/security material | Product strategy, security controls |
| Restricted | High-risk or regulated material | Secrets, credentials, customer/security incidents |

## Default Rule

Treat product strategy, security posture, and deployment architecture as confidential by default.
